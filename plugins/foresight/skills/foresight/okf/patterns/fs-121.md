# FS-121 · Step run under retries or reruns is not idempotent

Airflow retries, SQS redrive and same-day reruns re-execute steps that create DDL, emit terminal-failure events, append without dedup, or overwrite fixed keys from mutated inputs. The second attempt fails or duplicates side effects.

**Triggers**
- a task with retries running CREATE/append/notify
- an SQS handler that emits failure events and relies on redrive
- a request to remove a dedup guard from a retried job

**Guards**
- Make DDL IF NOT EXISTS / CREATE OR REPLACE and writes MERGE or overwrite-by-partition
- Emit terminal-failure side effects only on the final attempt
- Flag retry semantics before removing an idempotency guard
