# FS-112 · Change exceeds or deviates from the explicit ask

The agent adds things nobody asked for (feature flags, bypasses, filters, extra alarms, speculative parsing, one-off abstractions, refactors, version bumps, prod-mutating migrations), substitutes its own design, method or evidence source for the one named, or silently changes a derivation or invariant while doing a narrow edit. Reviewers must then unpick unrelated diff and the requested behavior is subtly different.

**Triggers**
- the request is a short imperative (remove X, rename Y, add Z to these N places)
- the user names a target function, method of verification, table set or rule
- copying a sibling pattern that carries a flag, guard or abstraction the ask didn't mention
- the diff is much larger than the ask, or touches a shared helper/lib for a single-service ask
- a delegation prompt paraphrases the user's rules for a subagent

**Guards**
- Before finishing, walk every hunk and map it to a sentence in the ask; revert hunks that map to nothing or call them out as questions
- Use the exact function, evidence source and tables the user named; ask before substituting
- Never add exceptions to an access/deny rule, relax an assert into a fallback, or delete a feature to resolve a bug without asking
- Pass the user's requirement verbatim to subagents instead of paraphrasing it
- Keep temporary instrumentation minimal and local; no structural rewrites
