# FS-122 · Integration or tool declared unavailable without discovering configured tools

Given a Slack/Notion/Linear link or a research task, the agent checks only its static tool list, tries a web fetch or browser automation, or dispatches a subagent type that lacks the needed tools, then stops or degrades instead of discovering the configured MCP namespaces.

**Triggers**
- the prompt contains a Slack/Notion/Linear URL or asks to write to one
- dispatching subagents for web research or external lookups

**Guards**
- Run the agent's dynamic tool/MCP discovery for the matching namespace before declaring anything unavailable
- Prefer MCP tools over browser automation
- Check the subagent type's tool set before delegating work that needs it
